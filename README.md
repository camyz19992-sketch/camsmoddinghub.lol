## 🛠️ QUICK STEP-BY-STEP SETUP

1. **Framework Setup:** Download and install the core **Frida Tools** environment.
2. **Menu Deployment:** Fetch the **MoonlitV2** or **Ion Cannon** configuration files from the active repository links listed above.
3. **Launch Protocol:** Restart your standalone VR headset immediately upon opening the initial ADB prompt to completely bypass any system interface lag.
4. **Optimization:** Always operate your headset in front of an active cooling fan to prevent thermal throttling and maintain a stable, locked 120 FPS performance tier.
